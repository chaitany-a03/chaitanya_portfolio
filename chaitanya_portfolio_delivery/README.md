# Chaitanya Patil Portfolio

A responsive React + TypeScript + Vite portfolio built from the five supplied visual references.

## Run in VS Code
1. Extract the ZIP.
2. Open the extracted `chaitanya_portfolio_delivery` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the localhost URL Vite prints (normally http://localhost:5173).

## Included
- Homepage composition with the supplied folded-arm particle portrait.
- About section based on the supplied resume.
- Horizontal project showcase: IDRO, ERP & CRM Operations Management System, TradeTrust.
- Skills grid based on resume skills.
- Contact details and supplied resume PDF.

Project artwork is illustrative UI concept art, not screenshots of deployed products. Public links are taken from the supplied resume. No X or Instagram account is invented.
